本 dir (design-intent/decisions/) はこの project の Architecture Decision Records (ADR) を保持する cluster です。 各 ADR は ADR-NNNN-<slug>.html の命名で配置します。

§1. Purpose

設計判断の理由 (WHY) を 1 決定 = 1 file で残す場所です。 決定時点の記録なので、 今の仕様は spec/ を見ます。

decisions/ は architectural decision の WHY を記録します。 spec (WHAT) の背景にある意思決定とその根拠を trace します。 主な人間読者は設計の経緯を時系列で辿る維持者です — ADR は決定時点の記録 (frozen) であり、 現在の WHAT は spec/ を参照してください。

§2. ADRs

ADR は 6 本です。 1 本目は実装言語と構成を Rust の単一 static binary に決めた記録、 2 本目は test / lint の toolchain を決めた記録、 3 本目は v1 の完全放棄に伴って憲法の 4 か所 (対話面・拘束条件・自己開発の既定・改訂の手続き) を書き換えた記録、 4 本目は MVP の状態の置き場と前の版と共有する接点の file の形 (追記だけの JSONL・環境変数を使わない・TOML subset) を決めた記録、 5 本目は 3 本目で決めた「承認を受け取る窓口は 1 つ」を、 適用し漏れていた A3 (依存 OSS の追加・削除) へ揃えた記録、 6 本目は構造検査が測る項目の一覧を、 実際に動いているもの (11 本) に合わせて差し替えた記録です。
