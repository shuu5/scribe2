設計判断記録 (ADR) scribe2 — heartbeat の停止と tick の健康

heartbeat は打刻の合図を指し、 席ごとに止められ、 管理 tick は止めない — 席の状態の dir の停止の記録 1 つで管理 tick は合図だけを送らず (起こし直し・退避・群の判定は撃つ)、 tick は周ごとに最後の周の打刻を書き、 seat tick status と doctor が健全と on/off を出し、 外の画面は file を読んで止める口は器の CLI を撃つ (ADR-0058 の「heartbeat = 管理 tick」の読みを部分 supersede・要件 FR78 / AC48 の新設と FR27 の語の改めを伴う)

ADR-0058 は管理 tick を器に戻し、 その呼び名として heartbeat を使った。 ADR-0068 は合図が梯子の列の末尾で止まると決めたが、 人が状況に応じて合図だけを止める口は無く、 tick 自体が動いているかも systemctl でしか見えない。 2026-09-26 に持ち主は、 tick は導入 project で既定で常時オン (口座の移動・状態把握の意味を持つ) にし、 heartbeat (黙った席へ送る合図) は席ごとに手で止められるようにし、 別 project の画面 (account board) にも tick の健全と heartbeat の on/off と止める口を作るべきだと要望し、 席の設計 (heartbeat = 打刻の合図・口は seat heartbeat off|on|status・止めるのは合図だけ・tick は周ごとに最後の周の打刻を書き健全は読み手が判じる) を裁定した (00:53Z)。 要件 FR78 / AC48 の新設と FR27 の語の改め (v0.25) を伴う。

この判断が約束すること (1 文サマリ)

この記録で「器」は scribe2 の本体、 「席」は人と AI が話す 1 つの session、 「見回り (管理 tick)」は席の外から周期で席を見る仕組み、 「合図」は見回りが黙った席に送る「続きを進めて」の 1 行です。 これまで heartbeat という語は見回りそのものの呼び名でした (ADR-0058)。 合図は待ちの列が尽きれば止まりますが、 人が状況に応じて合図だけを止める口は無く、 止めるには見回りの timer ごと止めるしかありませんでした。 それでは口座の移動や落ちた席の起こし直しも止まります。 2026-09-26 に持ち主は、 見回りは常にオンにし、 heartbeat (合図) は席ごとに手で止められるようにし、 別 project の画面にも見回りが健全に動いているか・合図が on か・止める口を作るべきだと要望し、 席の提案を裁定しました。 この記録は、 heartbeat の語を「合図」に改め、 席ごとの停止の記録 1 つで合図だけを止め (落ちた席の起こし直し・退避・群の判定はそのまま)、 見回りが毎周「最後に周った時刻と判定」を席の dir に残し、 status と doctor が健全と on/off を出し、 外の画面は file を読んで止める口は器の CLI を叩く、 と決めます。 要件書の FR78 / AC48 の新設と FR27 の語の改め (版 0.25) を伴い、 同じ PR で land します。

01 背景 / なぜこの判断が要るか

いま何が問題か (確定方式を決める力学)

なぜこの判断が要るのかを、 経緯 (heartbeat の語と止める口の不在)・要望と裁定・器の今の部品・これまでの決まり・この判断の範囲の 5 つから説明します。 前の決定 (ADR-0058) は見回りを器に戻し、 持ち主の裁定の語に合わせて heartbeat をその呼び名にしました。 後の決定 (ADR-0068) は合図の待ちを 30 分 → 1 時間 → 3 時間 → 6 時間 → 12 時間 → 24 時間 の列にし、 列が尽きたら止まると決めました。 けれども、 席を意図して休ませたい周や保守の周に合図だけを止める口は無く、 止めるには見回りの timer を退役させるしかなく、 それでは落ちた席の起こし直し・移動のための退避・群の移動の判定も止まります。 2026-09-26 に持ち主は、 見回りは導入 project で既定で常にオンにすべき (口座の移動や状態把握など意味が多い) だが heartbeat は状況に応じて止められるべきで、 手で見回りはそのまま heartbeat だけ止める簡単な方法を CLI に作るべきだ、 さらに別 project (tsuzuri) で作る画面にも見回りが健全に動いていることの表示・heartbeat が on かの表示・画面から off にする口を作るべきだ、 と要望しました。 席は、 heartbeat の語を「見回りが黙った席へ送る合図」に改めて見回りは tick のままとする形、 席ごとの停止の記録 1 つと CLI の口、 毎周の「最後に周った記録」、 status と doctor の見せ方、 画面は file を読み止める口は CLI を叩く形を提案し、 持ち主は推奨で進めると裁定しました。 器の部品を見ると、 見回りの 1 周は、 登録の読み → 窓が shell なら落ちた席の起こし直し → 移動の周なら退避 → 合図 (黙りの長さ・待ちの列・口座の門・入力欄の門) → 群の判定、 の順で、 毎周の判定を 1 行で標準出力に出し (journal が残す)、 合図を止める分岐はありません。 席ごとの「最後に周った時刻」の file も無く、 見回りの生死は systemctl でしか見えません。 決まりの側では、 道は 1 本 (書き手は器の 1 本)・宣言値と実測値と導出値を分ける (健全かは読む側が導く)・足すときに外す物を名指す・消えたら戻せない削除を断る (停止は消せば戻る)、 が効きます。 動かすのは、 語の指す先・停止の口・最後に周った記録・見せ方の 4 か所だけで、 見回りの判定の順・起こし直し・退避・群の判定・待ちの列・unit と周期・記録の種類は動かしません。

CTX1

経緯 — heartbeat黙った席へ送る合図 は管理 tick席を周期で見る仕組み の呼び名で、 合図を止める口は無い (ADR-0058 / ADR-0068)

ADR-0058 は管理 tick (席の外から周期で席を見て、 黙った席へ続きを促す 1 行 = 打刻の合図続きを促す 1 行を注入する仕組み) を器に戻し、 持ち主の裁定の語に合わせて heartbeat をその呼び名とした。 語彙 (vocabulary) の heartbeat も「ADR-0058 での管理 tick の呼び名」である。 ADR-0068 は合図の待ちを梯子の列 (30 分 → 1 時間 → 3 時間 → 6 時間 → 12 時間 → 24 時間) にし、 列が尽きた段で合図が止まると決めた。 人が状況に応じて (席を意図して休ませる・保守の周など) 合図だけを止める口は無く、 止めるには tick の timer (ADR-0064 の unit) を止めるしかないが、 それでは tick の他の仕事 (死んだ席の起こし直し・移動の周の退避・群の移動の判定) も止まる。

CTX2

要望と裁定 — tick は常時オン、 heartbeat は席ごとに止める、 画面にも

2026-09-26 に持ち主は、 tick は導入 project で既定で常時オンにすべき (口座の移動や状態把握など意味が多い) が、 heartbeat は状況に応じて止められるべきで、 24 時間まで伸びたら既定で止まる形はあるが、 手で tick はそのまま heartbeat だけ止める簡単な方法を CLI に作るべきだ、 さらに別 project (tsuzuri) で作る account board の画面にも、 tick が健全tick が周期どおり周っているに動いていることの表示・heartbeat が on かの表示・画面から heartbeat を off にする口を作るべきだ、 と要望した (00:48Z・要旨)。 席は heartbeat の語を「管理 tick が黙った席へ送る合図 (止められるもの)」に改め管理 tick は tick のままとする形、 席ごとの停止の記録合図を止めている印 1 つと CLI の口、 周ごとの最後の周の打刻、 status と doctor の見せ方、 画面は file を読み止める口は CLI を撃つ形を提案し、 持ち主は推奨で進めると裁定した (00:53Z・要旨)。 off で止めるのは合図だけで死んだ席の起こし直し落ちた席を起こす手は撃つ、 は前提として提示し異論は無かった。

CTX3

現物 — tick の 5 つの仕事・記録・語彙・CLI

main aa4bfe1 で、 管理 tick (seat/tick.rs) の周は front (登録 row の読み → 窓が shell なら死んだ席の起こし直し → 移動の周なら退避の門) → 打刻の合図 (黙りの初段・梯子の列・口座の門・入力欄の門) → back (群の判定・鮮度の窓に 1 回) の順で、 判定行tick が周ごとに出す 1 行 (decision= target= reason= pointer= step= consumed= move= launched= judged=) を stdout に出し、 systemd の journal がそれを残す。 合図を止める分岐は無く、 止まるのは列が尽きた段 (pointer=stopped) だけ。 tick が周ごとに残す記録は判定行と群の判定の打刻 (<群用 dir>/<群>.judged) だけで、 席ごとの「最後に周った時刻」の file は無い。 合図の記録は <state_dir>/seat/<target>/pointer-ladder (送った周だけ書く)。 送らない理由は NoopReason の閉じた列 (18 種・歯の母集団) で、 判定行の reason= の語。 CLI は seat tick (1 回) / tick install / tick uninstall。 unit (ADR-0064) は周期 (rules 行 seat.tick_interval_s・15 秒) だけを読む。 tick の生死は systemctl --user list-timers でしか見えない。

CTX4

憲法と既存の決定の向き (本 ADR の解釈)

C2 (経路は 1 本) から、 停止の記録の書き手は器の口 1 本で、 外の画面 (別 project の board) は記録を読んでよいが書かず、 止める・戻すは器の CLI を撃つ。 C10 (宣言値・実測値・導出値を分ける) から、 最後の周の打刻tick が最後に周った記録は実測値 (時刻・判定・理由) で、 「健全か」はそれを読む側の導出値 (経過が周期の 2 倍以内) であり tick は判じない。 C17 (足すときに何を外すかを名指す) から、 足すのは停止の記録 1 file・最後の周の打刻 1 file・NoopReason の変種 1 つ・CLI の verb 1 つ (heartbeat) と status の口・doctor の項目 2 つで、 外すのは無い (合図の停止は列の末尾の停止と別の口)。 N1 (消えたら戻せない削除を断る) から、 停止の記録は消す (on) ことで戻る可逆な形。 ADR-0058 の管理 tick を戻す機構・判定の列の順・fail-closed、 ADR-0064 の unit の導出、 ADR-0066 の群の判定、 ADR-0068 の梯子の列は本 ADR の前提で、 変えるのは heartbeat の語の指す先だけ。

CTX5

射程 — 動かすのは語・停止の口・健康の打刻・見せ方の 4 か所

動かすのは (1) heartbeat の語の指す先 (管理 tick → 打刻の合図)、 (2) 席ごとの停止の口 (seat heartbeat off|on|status・記録 <state_dir>/seat/<target>/heartbeat-off・tick は合図の段の前で読み off なら noop reason=heartbeat-off)、 (3) 最後の周の打刻 (<state_dir>/seat/<target>/tick-last・1 行 ts= decision= reason=・rc 1 の周も書く)、 (4) 見せ方 (seat tick status の 1 行 target= last= age= healthy= heartbeat= step= next=・doctor の席の行に heartbeat= と tick=) の 4 つ。 動かさないのは、 tick の判定の列の順・死んだ席の起こし直し・移動の周の退避・群の判定・梯子の列と記録・口座の門・入力欄の門・unit の導出と周期・event の種類 (打刻は event log に書かない)・rules 行。

02 判断を縛る力 / 評価の軸

選択肢を測るものさし (安全・速さ)

この判断を評価する 4 本のものさしです。 見回りは止めず合図だけ止めること (口座の移動と状態把握は止まらず、 席を促す合図だけが状況に応じて止まる)。 止める口は席ごとで可逆で裁定が要らないこと (席の dir の記録 1 つを置く／消すだけで、 規則の表や host の設定を書き換えない)。 健全さは記録で見せ判じるのは読む側であること (見回りは毎周「最後に周った時刻と判定」を書き、 健全かは経過が周期の 2 倍以内かで読む側が導く)。 書き手は器の 1 本であること (外の画面は file を読んでよいが書かず、 止める・戻すは器の CLI を叩く) です。

03 検討した選択肢 / 3 つの確定方式

それぞれの利点と欠点を並べる

候補を 5 つ並べます。 heartbeat を合図の呼び名にし・席ごとの停止の記録 1 つ・最後に周った記録・status と doctor で見せる案 (選んだ案)、 見回りの timer を止めて heartbeat off にする案、 off を規則の表 (host の設定) で持つ案、 最後に周った記録を出来事の log に書く案、 machine 全体の off を 1 つの file で持つ案です。 却下した 4 案にも利点を並べ、 退けた決め手が現物か分析かを各案に書きます。 timer を止める案は口も記録も増えない点で、 規則の表で持つ案は宣言値として設定に残る点で、 log に書く案は記録の置き場が 1 つに揃う点で、 machine 全体の off の案は保守の周に 1 回で全席を止められる点で、 選んだ案に勝ります。

OPT1heartbeat = 打刻の合図・席ごとの停止の記録 1 つ・最後の周の打刻・status と doctor で見せる採用

heartbeat の語を「管理 tick が黙った席へ送る合図」に改め、 管理 tick は tick のまま。 CLI に seat heartbeat off|on|status を足し、 off は席の状態の dir に停止の記録 (1 行 ts=) を一時 file → rename で置き、 on は消す。 tick は合図の段の前で記録を見て、 在れば decision=noop reason=heartbeat-off で合図を送らず、 死んだ席の起こし直し・移動の周の退避・群の判定はそのまま撃つ。 記録が在るのに読めない周も off。 tick は周ごとに最後の周の打刻 (1 行 ts= decision= reason=・rc 1 の周も) を席の状態の dir に書き、 seat tick status が席ごとに 1 行 (target= last= age= healthy= heartbeat= step= next=) を出し、 doctor の席の行に heartbeat= と tick= を足す。 健全 = 経過が周期の 2 倍以内 (読み手が判じる)。 外の画面は 2 つの file を読んで表示し、 off / on は器の CLI を撃つ。 決め手は現物 (持ち主の裁定)。

heartbeat の語を「見回りが黙った席へ送る合図」に改め、 見回りは tick のままにする案です。 CLI に seat heartbeat off|on|status を足し、 off は席の dir に停止の記録 (時刻 1 行) を置き、 on は消します。 見回りは合図を送る前に記録を見て、 在れば合図を送らず (判定の行は noop / heartbeat-off)、 落ちた席の起こし直し・退避・群の判定はそのまま撃ちます。 記録が在るのに読めない周も止めたと読みます。 見回りは毎周「最後に周った記録」(時刻・判定・理由) を席の dir に書き、 seat tick status が席ごとに 1 行 (最後の時刻・経過・健全か・on/off・段・次の合図) を出し、 doctor の席の行に 2 項目を足します。 健全かは経過が周期の 2 倍以内かで読む側が判じます。 外の画面は 2 つの file を読んで表示し、 止める・戻すは器の CLI を叩きます。 見回りの仕事は止まらず、 止める・戻すが戻せる記録 1 つで、 生死が file 1 つで分かり、 書き手が器の 1 本です。 代わりに、 席の dir に file が 2 つ増え毎周の書き込みが席の数だけ増えること、 off の席は起こし直し以外では起こされないこと、 要件書の改訂と前の決定の語の読みの置き換えを引き受けます。 決め手は現物 (持ち主の裁定) です。

+ 利点

  • tick の仕事 (起こし直し・退避・群の判定) は止まらず、 合図だけが席ごとに止まる (DR1)
  • 止める・戻すが記録 1 つの置く／消すで可逆、 裁定 id も host の面の編集も要らない (DR2)
  • tick の生死が systemctl を見ずに file 1 つで分かり、 別 project の画面が同じ file を読める (DR3)
  • 書き手が器の 1 本なので、 画面が壊れた記録を置く事故が無い (DR4)

− 欠点

  • 席の状態の dir に file が 2 つ増える (停止の記録・最後の周の打刻)。 周ごとの書き込み 1 回が席の数だけ増える (15 秒 × 席数・1 行の rename)
  • off の席は黙ったまま起こされない (合図が止まる) が、 死んだ席の起こし直しは撃つので、 起こし直した席は初手の合図だけを受ける
  • 要件 FR78 / AC48 の新設と FR27 の語の改め (v0.25) を伴い、 ADR-0058 の heartbeat の語の読みが本 ADR に置き換わる
OPT2tick の timer を止めて heartbeat off にする不採用

seat tick uninstall (ADR-0064) で unit を退役させ、 戻すときは install する。 決め手は現物 (持ち主の要望と逆)。

見回りの timer を退役させて heartbeat off にし、 戻すときは入れ直す案です。 口も記録も増えない点で勝ります。 けれども、 落ちた席の起こし直し・移動のための退避・群の判定も止まって口座の移動が止まり、 unit の導出と退役は host の駆動機構を触る重い口で、 状況に応じて頻繁に叩く口ではありません。 決め手は現物で、 持ち主の要望 (見回りは常にオン) と逆です。

+ 利点
