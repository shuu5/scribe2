設計判断記録 (ADR) scribe2 — 起こし直しは会話を運ぶ

席の起こし直しは打刻の会話 id を --resume で運ぶ — 群の移動と管理 tick の起こし直しは、 その席の状態の打刻の最終行の会話 id を起動行の末尾に --resume で渡して直前の会話の続きから始め、 対話の記録の file は複写せず、 復帰の道は機械の復帰の 1 本のまま (ADR-0049 の「対話の記録は運ばない」の節だけを supersede・要件 FR38 / FR59 の改訂を伴う)

ADR-0049 は群の移動を「新しい口座で新しい席を起こし、 対話の記録は運ばず、 復帰は機械の注入に任せる」と決め、 生きた対話を持ち越す案 (OPT3) を「記録の置き場の共有は host の設定で器の前提にできない・復帰の道が 2 本になる・器が対話の記録を読む口を持つ」の 3 つで退けた。 2026-09-25 の実測で、 群の移動と再起動の後の起こし直しは毎回まっさらな session を立て、 席は台帳と git から流れを組み直す手番を移動のたびに払い、 持ち主は「会話を reset する意味が無い」と裁定した (裁定 id user 2026-09-25T03:58Z)。 本 ADR は、 起こし直しが運ぶものを「その席の状態の打刻の最終行に hook が残した会話 id 1 つ」に限り、 起動行の末尾に --resume で渡すと決める。 対話の記録の file は複写せず、 器は記録を読まず、 復帰は機械の復帰の 1 本のまま (id が無い・形が違う周は今まで通り空で起こす)。 ADR-0049 の 3 つの理由は、 file を複写しない・器が記録を読まない・復帰の道は 1 本のままで、 どれも本 ADR には当たらない。 要件 FR38 / FR59 (v0.23) の改訂を伴う。

この判断が約束すること (1 文サマリ)

この記録で「器」は scribe2 の本体、 「席」は人と AI が話す 1 つの session、 「口座」は席が使う Claude Code の login 単位、 「群」は同じ口座を共有する project のかたまり、 「起こし直し」は古い席を終えて同じ窓に席を立て直すことです。 前の決定 (ADR-0049) は、 群ごと別の口座へ移るときは新しい口座で新しい席を起こし、 それまでの会話 (対話の記録) は運ばず、 続きは器が台帳と git から組み直す (機械の復帰) と決めました。 会話を持ち越す案は、 記録の置き場が口座を跨いで共有かどうかは machine の設定なので器の前提にできない・続きを拾う道が 2 本になる・器が会話の記録を読むことになる、 の 3 つで退けられました。 2026-09-25 の実測では、 群の移動と再起動の後の起こし直しは毎回まっさらな session を立て、 持ち主が席ごとに前の会話を探して手で開き直し、 「会話を reset する意味が無い」と裁定しました。 この記録は、 起こし直しが運ぶものを「その席の状態の打刻 (席の hook が残す 1 行) に残った会話の id 1 つ」に限り、 席を起こす 1 行の末尾に --resume で渡すと決めます。 会話の記録の file は複写せず、 器は記録を読まず、 記録が新しい口座から見えるかは開く側 (claude) に任せ、 続きを拾う道は機械の復帰の 1 本のままです。 前の決定の 3 つの理由のうち、 「器が記録を読む」と「道が 2 本になる」は当たらず、 「置き場の共有を前提にする」は器が判じない形 (見えなければ開く側が断る) で避けます。 前の決定のうち「運ばない」の節と、 「持ち越しは要らない」のものさしと、 「続きは測り直して入れ直すもの」の原則の 3 つが、 この記録に置き換わります。 要件書の FR38 / FR59 (版 0.23) の改訂を伴い、 同じ PR で land します。

01 背景 / なぜこの判断が要るか

いま何が問題か (確定方式を決める力学)

なぜこの判断が要るのかを、 経緯・実測と裁定・器の今の部品・要件書との関係・これまでの決まり・この判断の範囲の 6 つから説明します。 前の決定 (ADR-0049) は、 群ごと別の口座へ移るときは新しい口座で新しい席を起こし、 会話の記録は運ばず、 続きは器が台帳と git と圧縮の直前の 1 枠から組み直すと決め、 会話を持ち越す案を 3 つの理由 (記録の置き場が共有かは machine の設定・続きを拾う道が 2 本になる・器が記録を読む) で退けました。 2026-09-25 の実測では、 群の移動と再起動の後の起こし直しはどの席でもまっさらな session を立て、 持ち主は席ごとに前の会話を探して手で開き直し、 「会話を reset する意味が無い」と裁定しました。 同じ日の別の裁定 (ADR-0066) は群の口座の移動を含めて器が完全に自律する方針を受諾しており、 起こし直しのたびに人が会話を探す手番はその方針に反します。 器の部品を見ると、 席の状態の打刻には既に会話の id が残っていて、 席を起こす入力は末尾に足す語 (carry) を持ち、 人が使う短い形はそれで --continue や --resume を渡しています。 見回り (管理 tick) の起こしと 1 周の群の手番の起こし直しは、 その語を空で撃っています。 会話の記録の file は claude が口座の設定 dir の下に置き、 この machine では口座を跨いで同じ場所を指していますが、 それは machine の設定であって器は読みません。 要件書では、 FR38 が「会話の記録は運ばない」と書き、 FR59 (席の起動) は起こし直しに何を運ぶかを書いていないので、 この判断は両方の改訂を伴います。 決まりの側では、 machine 固有の値で分岐しない・道は 1 本・状態は型で運ぶ・足すときに外す物を名指す、 が効き、 器は「記録が見えるか」を判じず id を渡すだけ、 足すのは打刻の id の読み手 1 本と末尾の 1 語、 外すのは前の決定の「運ばない」の 1 節だけ、 と読みます。 動かすのは起こし直しの 1 行の末尾 1 語だけで、 席の起動の他の全部・人が使う短い形・機械の復帰・群の移動の判定と記録・退避の合図・会話の記録の置き場は動かしません。

CTX1

経緯 — 対話の記録claude が残す会話の fileを運ばないと決めた前の決定と、 その理由 3 つ

ADR-0049 は席の口座を project の群で持ち、 上限に当たった周は群単位で 1 回だけ移り先を決め、 新しい口座で新しい席を起こして復帰を機械の注入 (台帳の行・git の現在地・圧縮の直前の 1 枠) に任せると決めた。 生きた対話を持ち越して別の口座へ移る案 (OPT3) は、 (1) 対話の記録の置き場が共有かどうかは host の設定で、 器が前提にすると host 固有の値で分岐する (N3)、 (2) 復帰の道が 2 本になる (圧縮・異常終了は機械の復帰・移動だけ持ち越し)、 (3) 器が対話の記録を読む口を持つことになる、 の 3 つで退けられ、 決定は「対話の記録 SHALL NOT 運ばず」と書かれた。 要件 FR38 はそれを「新しい口座で席を起こし直し (対話の記録は運ばない・ADR-0049)」と写した。

CTX2

実測と裁定 — 起こし直しのたびに会話が消える

2026-09-25 の実測で、 群の移動 (黒 1 → 黒 6) と host の再起動の後の起こし直しは、 どの席でもまっさらな session を立てた。 席は起こされるたびに台帳と git から直前の流れを組み直し、 持ち主は席ごとに前の会話の id を探して手で resume を撃った。 持ち主は「移動後は会話を resume する。 会話を reset する意味が無い」と裁定した (裁定 id user 2026-09-25T03:58Z・要旨だけを写す・逐語は非公開の作業記録簿に在る)。 同じ日の裁定 (2026-09-25T04:13Z・ADR-0066) は群の口座の移動を含めて器が完全に自律する方針を受諾しており、 起こし直しのたびに人が会話を探す手番はその方針に反する。

CTX3

現物 — 打刻に会話 idclaude の session の名前 が既に在り、 起動の入力は末尾の語を受ける

base 42062de で、 席の状態の打刻席の hook が残す 1 行 (席の hook が SessionStart / UserPromptSubmit / Stop で置き場の file に 1 行ずつ残す記録) は state・event・ts に加えて sid (claude の session id・会話 id) を持つ。 席の起動の入力 (Launch) は carry (起動行席を起こす 1 行の commandの末尾に足す語) を持ち、 席の短い形 -c / -r はこれで --continue / --resume <id> を渡す (account-lifecycle.md §18)。 管理 tick席を周期で見る仕組み の起こし (wake) と dispatch の群の段の起こし直し (relaunch) は carry を空で撃つ (seat-heartbeat.md §4 形 3・account-lifecycle.md §20 形 6)。 対話の記録の file は口座の設定 dir の下の projects/<anchor> に claude が置き、 この host では口座を跨いで同じ 1 dir を指す symlink になっているが、 それは host の設定であって器は読まない。 --resume <id> は claude 自身の口で、 器はそれを起動行の末尾に置くだけである。 打刻の sid の読み手は行 f (s2-07l.626) が state.rs に 1 本置き、 行 g (s2-07l.628) が群の段の relaunch にも同じ 1 本を渡す。

CTX4

要件文との関係 — FR38 と FR59 の改訂

SRS v0.22 の FR38 は「新しい口座で席を起こし直し (対話の記録は運ばない・ADR-0049)」と書き、 FR59 (席の起動) は起こし直しの周に何を運ぶかを書かない。 本 ADR は FR38 の同じ節を「起こし直しは席の起動 (FR59) で、 その席の状態の打刻の最終行の会話 id を --resume で運んで直前の会話の続きから始め、 対話の記録の file は複写しない」に改め、 FR59 に「起こし直しの周は打刻の最終行の会話 id を起動行の末尾に --resume で運ぶ (会話 id の形でない周は運ばない・記録の file は複写しない)」を足す改訂 (v0.23) を伴う。 改訂は持ち主が spec の編集の口で行い、 本 ADR と同じ PR で land する。

CTX5

憲法と既存の決定の向き (本 ADR の解釈)

N3 (host 固有の値で code を分岐させない) は、 器が「記録の置き場が共有か」を判じて分岐する形を禁じる。 本 ADR は判じない — 器は id を渡すだけで、 記録が新しい口座から見えるかは claude が起動の周に決め、 見えない周は claude が resume を断って席が立たない (起動の結果の語は今の launch-unconfirmed / input-unknown のまま・器は記録を読みに行かない)。 C2 (経路は 1 本) は復帰の道を 2 本にしないことを求め、 本 ADR の復帰は機械の復帰器が続きを組み直す道 (台帳・git・圧縮の直前の 1 枠から席の指示文を組む) の 1 本のままで、 --resume はその手前で claude が会話を開く口に過ぎない。 C3 (状態は型で運ぶ) と C10 (宣言値・実測値・導出値を分ける) から、 運ぶ id は打刻 (実測の記録) の字面だけで、 pane の字面や projects dir の走査からは取らない。 C17 (足すときに何を外すかを名指す) は、 本 ADR が足すのは打刻の sid の読み手 1 本と carry への 1 語で、 外すのは ADR-0049 の「運ばない」の 1 節だけと読む。 ADR-0065 (trust の印は席の起動が置く) と ADR-0066 (tick が判定を撃つ) は本 ADR の前提で不変。 ADR-0045 §2 (2) (席は自分を起こし直さない) は不変で、 運ぶのは起こす側 (tick・群の段) である。

CTX6

射程 — 動かすのは起こし直しの起動行の末尾 1 語だけ

動かすのは、 管理 tick の起こし (seat-heartbeat.md §7 形 3・行 f) と dispatch の群の段の起こし直し (account-lifecycle.md §20 形 6 の改め・§8・行 g) が起動行の末尾に置く carry を、 「空」から「打刻の最終行の sid が会話 id の形 (UUID) なら --resume <sid>・無い / 形が違う周は空」に変えることの 1 つ。 動かさないのは、 席の起動の他の全部 (役割・口座の解決・登録 row・trust の印・窓と入力欄の門・起動行の雛形)、 席の短い形 -c / -r (人が明示的に運ぶ口・今のまま)、 機械の復帰 (席の指示文の生成・圧縮の直前の 1 枠)、 群の移動の判定と記録 (ADR-0049・ADR-0066)、 退避の合図、 対話の記録の置き場 (器は触らない・読まない・複写しない)。

02 判断を縛る力 / 評価の軸

選択肢を測るものさし (安全・速さ)

この判断を評価する 4 本のものさしです。 起こし直しで会話が消えないこと (移動と再起動の後に人が会話を探して開き直す手番を無くす)。 machine の設定で分岐しないこと (器は記録の置き場が共有かを判じず、 記録を読まず、 複写しない)。 続きを拾う道は 1 本のままにすること (機械の復帰は変えず、 運ぶのは id 1 語だけ)。 運ぶ値は実測の記録から取ること (状態の打刻の最終行の id の字面だけを、 会話の id の形のときに限って運ぶ) です。

03 検討した選択肢 / 3 つの確定方式

それぞれの利点と欠点を並べる

候補を 4 つ並べます。 状態の打刻の最終行の会話の id を --resume で運ぶ案 (選んだ案・記録の file は複写せず、 続きを拾う道は機械の復帰のまま)、 運ばない案 (前の決定のまま)、 会話の記録の file を新しい口座の置き場へ複写する案、 --continue で最新の会話を開かせる案です。 却下した 3 案にも利点を並べ、 退けた決め手が現物か分析かを各案に書きます。 運ばない案は器が id も記録も扱わない点で、 複写する案は置き場が共有でない machine でも会話が続く点で、 --continue の案は打刻の id の読み手が要らない点で、 選んだ案に勝ります。

OPT1起こし直しは打刻の最終行の会話 id を --resume で運ぶ (記録の file は複写しない・復帰は機械の復帰のまま)採用

管理 tick の起こしと dispatch の群の段の起こし直しが、 その席の状態の打刻の最終行の sid を読み、 会話 id の形 (UUID) なら起動行の末尾に --resume <sid> を置いて起こす。 sid が無い・形が違う周は今まで通り空で起こす。 読み手は state.rs の 1 本で、 tick と群の段が同じ 1 本を呼ぶ。 器は対話の記録の file を読まず複写せず、 記録が新しい口座から見えるかは claude が起動の周に決める。 機械の復帰 (席の指示文) は今まで通り session の開始で出る。 決め手は分析 (裁定を、 器に記録の読み手を足さず 1 語で満たす)。

見回り (管理 tick) の起こしと 1 周の群の手番の起こし直しが、 その席の状態の打刻の最終行に残った会話の id を読み、 id の形 (UUID) なら席を起こす 1 行の末尾に --resume とその id を置いて起こす案です。 id が無い・形が違うときは今まで通り空で起こします。 読み手は打刻の部品に 1 本で、 見回りと群の手番が同じ 1 本を呼びます。 器は会話の記録の file を読まず複写せず、 記録が新しい口座から見えるかは claude が起動のときに決めます。 続きを拾う道 (機械の復帰・席の指示文) は今まで通り session の開始で出ます。 移動と再起動の後に会話が続き、 器は machine の設定で分岐せず、 道は 1 本のまま、 運ぶ値は実測の記録の字面だけ、 人が使う短い形と同じ末尾の 1 語で入力の形も変えません。 代わりに、 記録の置き場が口座を跨いで見えない machine では claude が起動を断り、 打刻が進まないので人が起こすまで席が立たないこと (空で起こし直す逃げ道は足しません)、 要件書の改訂を伴うこと、 前の口座で作った会話の量を新しい口座に持ち込むことを引き受けます。 決め手は分析で、 持ち主の決定を、 器に記録の読み手を足さず 1 語で満たす案でした。

+ 利点

  • 移動と再起動の後に会話が続き、 人が会話を探して resume を撃つ手番が消える (DR1)
  • 器は記録の置き場が共有かを判じず、 記録を読まず、 複写しない。 見えない周は claude が断り、 器は今の起動の結果の語で止まる (DR2)
  • 復帰の道は機械の復帰の 1 本のまま。 --resume は claude が会話を開く口で、 器の復帰の経路に 2 本目を足さない (DR3)
  • 運ぶ値は打刻 (hook が残した実測の記録) の字面だけで、 形が違う周は運ばない (DR4)
  • 席の短い形 -c / -r と同じ carry の 1 語で、 起動の入力の形を変えない (C17)

− 欠点

  • 対話の記録の置き場が口座を跨いで見えない host では、 --resume 付きの起動を claude が断り、 打刻が進まないので次の周も同じ id で断られ、 人が起こすまで席が立たない (器は記録を読まないので事前に判じない・起動の結果の語は今の launch-unconfirmed / input-unknown のまま・空で起こし直す枝は足さない)
  • 要件 FR38 / FR59 の改訂を伴う
  • 前の会話をそのまま続けるので、 前の口座で作った文脈の量 (context の消費) を新しい口座に持ち込む
OPT2運ばない (ADR-0049 のまま)不採用

起こし直しは今まで通りまっさらな session を立て、 復帰は機械の復帰だけに任せる。 決め手は現物 (2026-09-25 の実測と裁定)。

  • 器は id も記録も扱わず、 host の設定に一切依らない

− 欠点

  • 起こし直しのたびに会話が消え、 席が流れを組み直す手番と、 人が会話を探して resume を撃つ手番を移動のたびに払う (2026-09-25 の実測) (DR1)
  • 持ち主の裁定 (会話を reset する意味が無い) に反する (DR1)
OPT3対話の記録の file を新しい口座の置き場へ複写して起こす不採用

ADR-0049 OPT3 の形。 器が前の口座の projects dir から記録の file を新しい口座の置き場へ複写し、 起動行を再現する。 決め手は分析 (ADR-0049 の理由 3 つがそのまま当たる)。

− 欠点

  • 置き場が共有の host では複写が二重になり、 器が「共有か」を判じて分岐する (N3) (DR2)
  • 復帰の道が 2 本になる (複写した記録と機械の復帰) (DR3)
OPT4--continue で最新の会話を開く不採用

− 欠点

  • 最新の会話は起こす席のものとは限らない (同じ anchor で開いた小さな session・別の席の会話に外れる)。 id を名指さない (DR4)
  • 打刻に sid が在るのに使わず、 claude の走査に任せる (実測の記録より弱い出所) (DR4)
04 採用した判断 / どの方式を選ぶか

選んだ方式と、 それが守る要件 (cross-doc 照会)

選んだ案と、 それが要件書のどの要件を支えるかを示します。 席の起こし直し (群の移動の周の 1 周の群の手番と、 見回りが窓が shell に戻った席を起こす周) は、 その席の状態の打刻の最終行に残った会話の id を読み、 id の形 (UUID) なら席を起こす 1 行の末尾に --resume とその id を置いて起こし、 id が無い・形が違うときは今まで通り空で起こします。 id の読み手は打刻の部品に 1 本で、 見回りの起こしと群の手番の起こし直しが同じ 1 本を呼びます。 器は会話の記録の file を読まず、 複写せず、 記録の置き場が口座を跨いで共有かを判じません。 記録が新しい口座から見えるかは claude が起動のときに決め、 見えなければ席は立たず、 器は今までと同じ起動の結果の語で止まります。 続きを拾う道は機械の復帰 (台帳の行・git の現在地・圧縮の直前の 1 枠から席の指示文を組み、 session の開始で出す) の 1 本のままで、 --resume は claude が会話を開く口であって器の道ではありません。 運ぶ値は打刻の字面だけで、 画面の文字や記録の置き場の走査からは取りません。 席の登録 row の起動の雛形には --resume を載せず、 値は起こすときに末尾に足します。 人が使う短い形 (-c / -r)・退避の合図・群の移動の判定と記録・信じた印・席の指示文の生成は変えません。 前の決定 (ADR-0049) のうち「会話の記録は運ばない」の節・「持ち越しは要らない」のものさし・「続きは測り直して入れ直すもの」の原則の 3 つを置き換え、 他 (群・鍵・記録・移り先の決め方・新しい口座で新しい席を起こす・続きは機械の復帰) は保ちます。 要件書では、 FR38 の「会話の記録は運ばない」を「起こし直しは席の起動で、 打刻の会話の id を --resume で運んで直前の会話の続きから始め、 記録の file は複写しない」に改める根拠になり、 FR59 に「起こし直しのときは打刻の会話の id を末尾に --resume で運ぶ」を足す根拠になり、 見回り (FR27) の起こし直しが運ぶ 1 語を決め、 席の登録 row (FR40) の雛形の形は変えないことを主張します。

採用 — OPT1

席の起こし直し (群の移動の周の dispatch の群の段と、 管理 tick が窓が shell に戻った席を起こす周) SHALL その席の状態の打刻の最終行の sid を読み、 会話 id の形 (UUID) の周は起動行の末尾に --resume <sid> を置いて起こし、 sid が無い・形が違う周は空で起こす (今まで通り)。 読み手 SHALL 打刻の module に 1 本で、 tick の起こしと群の段の起こし直しが同じ 1 本を呼ぶ (C2)。 器 SHALL NOT 対話の記録の file を読まず、 複写せず、 記録の置き場が口座を跨いで共有かを判じない (N3) — 記録が新しい口座から見えるかは claude が起動の周に決め、 見えない周は席の起動の今の結果の語 (launch-unconfirmed / input-unknown) で止まる。 復帰 SHALL 機械の復帰 (台帳の行・git の現在地・圧縮の直前の 1 枠から席の指示文を組み session の開始で出す) の 1 本のままで、 --resume は claude が会話を開く口であって器の復帰の経路ではない。 運ぶ値 SHALL 打刻の字面だけで、 pane の字面や projects dir の走査から取らない (C3・C10)。 登録 row の起動の雛形 SHALL NOT --resume を載せない (雛形は口座と anchor の形だけ・値は起動の周に carry で足す)。 席の短い形 -c / -r・退避の合図・群の移動の判定と記録・trust の印・席の指示文の生成は変えない。 本 ADR SHALL ADR-0049 のうち、 決定の「対話の記録 SHALL NOT 運ばず」の節・DR3 (移動に生きた対話の持ち越しは要らない)・原則の「席の続きは運ぶものでなく測り直して入れ直すもの」の 3 つを置き換え (本 ADR の原則「運ぶのは会話 id 1 語・記録は運ばない」が代わる)、 他 (群・鍵・記録・移り先の 3 条件・新しい口座で新しい席を起こす・復帰は機械の注入・OPT3 の却下) は保つ。 要件 FR38 / FR59 (SRS v0.23) の改訂を伴い、 同じ PR で land する。

席の起こし直し (群の移動の周の 1 周の群の手番と、 見回りが窓が shell に戻った席を起こす周) は、 その席の状態の打刻の最終行に残った会話の id を読み、 id の形 (UUID) のときは席を起こす 1 行の末尾に --resume とその id を置いて起こし、 id が無い・形が違うときは今まで通り空で起こします。 読み手は打刻の部品に 1 本で、 見回りの起こしと群の手番の起こし直しが同じ 1 本を呼びます (道は 1 本)。 器は会話の記録の file を読まず、 複写せず、 記録の置き場が口座を跨いで共有かを判じません (machine 固有の値で分岐しない)。 記録が新しい口座から見えるかは claude が起動のときに決め、 見えなければ席は立たず、 器は今までと同じ起動の結果の語で止まります。 続きを拾う道は機械の復帰 (台帳の行・git の現在地・圧縮の直前の 1 枠から席の指示文を組み、 session の開始で出す) の 1 本のままで、 --resume は claude が会話を開く口であって器の道ではありません。 運ぶ値は打刻の字面だけで、 画面の文字や記録の置き場の走査からは取りません。 席の登録 row の起動の雛形には --resume を載せず (雛形は口座と repo の形だけ)、 値は起こすときに末尾に足します。 人が使う短い形 (-c / -r)・退避の合図・群の移動の判定と記録・信じた印・席の指示文の生成は変えません。 前の決定 (ADR-0049) のうち「会話の記録は運ばない」の節・「持ち越しは要らない」のものさし・「続きは測り直して入れ直すもの」の原則の 3 つを置き換え、 他 (群・鍵・記録・移り先の決め方・新しい口座で新しい席を起こす・続きは機械の復帰) は保ちます。 要件書の FR38 / FR59 (版 0.23) の改訂を伴い、 同じ PR で land します。 持ち主の決定は、 群の移動の後は会話を resume する、 会話を reset する意味が無い、 という方針の受諾でした。 2026-09-25 の実測で、 群の移動と再起動の後の起こし直しがどの席でもまっさらな session を立て、 持ち主が席ごとに前の会話を探して手で開き直したことが、 前の決定 (ADR-0049) の「運ばない」が完全自律の方針 (ADR-0066) の下では人の手番を残す証拠です。 打刻の id を --resume で運ぶ形にしたのは、 席の状態の打刻に既に会話の id が残っていて、 席を起こす入力が末尾に足す語を既に持ち、 人が使う短い形がそれで同じ口を使っているからで、 足すのは id の読み手 1 本と末尾の 1 語に閉じます。 記録の file を複写する案を退けたのは、 前の決定の 3 つの理由 (器が記録を読む・置き場が共有かで分岐する・道が 2 本になる) がそのまま当たるからで、 選んだ案にはどれも当たりません: 器は id を渡すだけで記録を読まず、 共有かを判じず、 続きを拾う道は機械の復帰のままです。 --continue に任せる案を退けたのは、 最新の会話が起こす席のものとは限らず、 打刻に在る実測の id より弱い出所に頼るからです。 運ばない案を退けたのは、 実測と決定がそれを否定したからです。 記録が新しい口座から見えない machine で、 claude が断り打刻が進まず人が起こすまで席が立たないことは、 器が事前に判じない (判じれば machine の設定で分岐する) 代償として引き受け (空で起こし直す逃げ道はこの記録では足しません)、 前の口座の会話の量を持ち込むこと・要件書の改訂を伴うこと・id の形でない打刻は運ばないことも代償として引き受けます。

FR38rationaleFR38 は群の移動の起こし直しを「新しい口座で席を起こし直し (対話の記録は運ばない・ADR-0049)」と書いていた。 本 ADR はその節を「起こし直しは席の起動 (FR59) で、 打刻の最終行の会話 id を --resume で運んで直前の会話の続きから始め、 対話の記録の file は複写しない」に改める根拠を与える (裁定 2026-09-25T03:58Z・ADR-0049 の理由 3 つがどれも当たらない)。
FR59rationaleFR59 は席の起動が起動行を導出し登録 row を先に書くことを求めるが、 起こし直しの周に何を運ぶかは書いていなかった。 本 ADR は「起こし直しの周は打刻の最終行の会話 id を起動行の末尾に --resume で運ぶ (会話 id の形でない周は運ばない・記録の file は複写しない)」を足す根拠を与える。

05 結果 / 良い面とトレードオフ

この判断で何が良くなり、 何を引き受けるか

この判断で良くなること 3 つと、 代わりに引き受けること 4 つです。 良くなるのは、 群の移動と再起動の後の起こし直しで会話が続き、 席が流れを組み直す手番と人が会話を探して開き直す手番が消えること、 器は記録を読まず複写せず置き場が共有かを判じないので machine 固有の値で分岐しない線が保たれること、 続きを拾う道が機械の復帰の 1 本のままで足すのは id の読み手 1 本と末尾の 1 語だけであることです。 引き受けるのは、 記録の置き場が口座を跨いで見えない machine では --resume 付きの起動を claude が断り、 打刻が進まないので次の周も同じ id で断られ続け、 人が席を起こすまで席が立たないこと (器は事前に判じず、 空で起こし直す逃げ道はこの記録では足しません)、 要件書の FR38 / FR59 の改訂を伴い前の決定の 1 節が置き換わること、 前の口座で作った会話の量 (context の消費) を新しい口座に持ち込むこと、 打刻の id が会話の id の形でないときは運ばないことです。
