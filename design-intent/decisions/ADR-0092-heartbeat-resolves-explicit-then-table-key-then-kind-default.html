設計判断記録 (ADR) scribe2 — heartbeat の決め方

heartbeat の実効の値は明示の記録 → 群の表の行の任意 key → 置き場の種類の既定の順で決まり、 決まり方を 3 語で名乗る — 口は seat heartbeat on|off|default|status で、 on と off は明示の記録を 1 つ置いて他方を消し、 default は両方を消し、 park の区画の席は既定で合図を受けない (ADR-0070 の停止の口の形を部分 supersede)

ADR-0070 は heartbeat (管理 tick が黙った席へ送る打刻の合図) を席ごとの停止の記録の有無で決め、 記録が無い席には全部送った。 席は残すが日々は動かさない置き場 (park の区画) の席には既定で合図を送らず、 それでも合図を受けたい席は表せるようにするため、 本 ADR は明示 on と明示 off の 2 つの記録と、 群の表の行の任意 key と、 置き場の種類の既定から heartbeat の値を決める。

この判断が約束すること (1 文サマリ)

この記録で「器」は scribe2 の本体、 「席」は人と AI が話す 1 つの session、 「見回り (管理 tick)」は席の外から周期で席を見る仕組み、 「合図 (heartbeat)」は見回りが黙った席へ送る「続きを進めて」の 1 行です。 これまで合図を送るかは、 席ごとの停止の記録が在るか無いかだけで決まり、 記録が無い席には全部送っていました (ADR-0070)。 持ち主は、 席は残すが日々は動かさない置き場 (park の区画) の席には既定で合図を送らず (合図で token を使わない)、 それでも合図を受けたい席は表せるようにすると裁定しました (2026-09-28)。 この記録は、 口を seat heartbeat on|off|default|status にし、 on と off は席ごとの明示の記録を 1 つ置き、 default はそれを消すこと、 合図を送るかは「明示の記録 → 群の表の行の key → 置き場の種類の既定 (群は送る・park の区画は送らない・どこにも属さない席は送る)」の順で決め、 どこで決まったかを 3 語 (explicit・group・default) で名乗ることを決めます。

01 背景 / なぜこの判断が要るか

いま何が問題か (確定方式を決める力学)

なぜこの判断が要るのかを、 経緯 (合図を送るかは停止の記録の有無の 2 値)・要望と裁定 (park の区画の席は既定で送らず、 それでも受けたい席を表す)・機序 (2 値の口は既定を持てない)・憲法と既存の決定の向き・この判断の範囲の 5 つから説明します。 前の決定 (ADR-0070) は、 見回りは止めずに合図だけを席ごとに止める口を作りましたが、 止めていない席は全部「送る」でした。

CTX1

経緯 — heartbeat は席ごとの停止の記録の有無の 2 値 (ADR-0070)

ADR-0070 は heartbeat を、 管理 tick席を周期で見る仕組み が黙った席へ送る打刻の合図続きを促す 1 行の呼び名とし、 口 seat heartbeat off|on|status を足した。 off は席の状態の dir席ごとの記録の置き場 に停止の記録 (1 行・時刻) を置き、 on はそれを消す。 管理 tick は合図の段の前で記録を読み、 在れば合図を送らず判定行を noop reason=heartbeat-off とし、 死んだ席の起こし直し・移動の周の退避・群の移動の判定はそのまま撃つ。 記録が在るのに読めない周も off と読む。 外の画面は記録の file を読んで on / off を出し、 止める・戻すは器の口を撃つ。 ADR-0070 は off を host の設定に席ごとの行で持つ案を、 席を休ませるたびに設定の編集と裁定が要るとして退けた。 値は記録の有無だけで決まり、 記録が無い席は全部 on である。

CTX2

要望と裁定 — park の区画口座を占めない区画の席は既定で合図を受けず、 それでも受けたい席を表す

持ち主は、 席は残すが日々は動かさない repo の置き場 (park の区画・群の表の名 Tier9 の行・ADR-0091) の席には既定で合図を送らない (合図で token を使わない) と裁定した (2026-09-28T01:55Z)。 あわせて、 heartbeat の記録を明示 on・明示 off・既定の 3 値にし、 口を seat heartbeat on|off|default とする形と、 群ごとの既定を群の表かたまりを宣言する表の行の任意 key heartbeat で持ち、 key が無ければ群は on・park の区画は off・どこにも属さない席は on とする形を、 推奨のまま裁定した (2026-09-28T02:00Z)。 要旨だけを写し、 逐語は台帳にだけ在る。

CTX3

機序 — 2 値の口は既定を持てない

ADR-0070 の口は「停止の記録が在れば off・無ければ on」の 2 値で、 記録が無い状態が on に決まっている。 park の区画の席を既定で off にするには、 記録が無い状態の意味を置き場で変えるか、 誰かが停止の記録を置くしかない。 前者では、 既定が off の席で合図を受けたい意志を表す記録が無い (on は記録を消すだけで、 消した後は既定の off に戻る)。 後者では、 口の外に記録の書き手が増える。 外の画面が記録の file の有無を on / off と読む形も、 既定が置き場で変わると実際に合図を送るかと食い違う。

CTX4

憲法と既存の決定の向き (本 ADR の解釈)

C2 (選定は 1 つの列の上の 1 つの関数で、 適用の順は列の宣言順だけから取る) から、 heartbeat の実効の値合図を送るかの値を決める順は、 決まり方値がどこで決まったかの閉じた 3 語 (explicit・group・default) の宣言順として 1 本の関数が持つ。 C10 (宣言値・実測値・導出値・実効の値を型で分ける) から、 明示の記録席ごとに置く札と群の表の行の key は宣言した値で、 実効の値は管理 tick と口がその周に記録と host の面を読んで決める値であり、 決まり方の語でどの宣言から来たかを名乗る。 記録の file の有無そのものを実効の値と読まない。 C17.2 (足すときに外す物を名指す) から、 足すのは明示 on の記録 1 つ・群の表の行の任意 key 1 つ・口の default・決まり方の 3 語で、 外すのは ADR-0070 の「停止の記録が無ければ on」の読みである。 N1 (消えたら戻せない削除を断る) から、 明示の記録は口で置き直せば戻る可逆な形のままにする。 ADR-0070 の、 合図だけを止めて管理 tick は止めないこと・最後の周の打刻・健全を読み手が判じること・記録の書き手が器の口 1 本であること・打刻を event log に書かないことは前提で、 変えない。

CTX5

射程 — 動かすのは口の形・決まる順・見せ方の 3 か所

動かすのは (1) 口の形 (seat heartbeat on|off|default|status・on と off は明示の記録を 1 つ置いて他方を消し・default は両方を消す)、 (2) heartbeat の実効の値の決まる順 (明示の記録 → 群の表の行の任意 key heartbeat → 置き場の種類の既定置き場で決まる既定) と決まり方の 3 語、 (3) 見せ方 (seat tick status に決まり方を足して 7 項目・seat heartbeat status は実効の値と決まり方と最後の周の打刻最後に周った記録の 3 項目・doctor の席の行の heartbeat は実効の値) の 3 つ。 動かさないのは、 管理 tick の判定の列の順・合図を送らない周の判定行の理由 heartbeat-off・off の周も撃つ起こし直しと退避と群の移動の判定・最後の周の打刻の形と健全の読み・梯子の列と記録・rules 行・event の種類。 park の区画そのもの (名 Tier9 の行・席の口座の決め方・park の移り先の判定) は ADR-0091 が持つ。

02 判断を縛る力 / 評価の軸

選択肢を測るものさし (安全・速さ)

この判断を評価する 4 本のものさしです。 置き場の種類で既定が変わること (park の区画の席は何もしなくても合図を受けない)。 既定と違う席の意志を、 置く／消すだけで戻せる記録で表せること。 記録の書き手と値の決まる順がそれぞれ 1 本であること。 値とその出所を、 外から口の出力で読めることです。

DR1置き場の種類で既定が変わる — park の区画の席は記録を置かなくても合図を受けず、 合図で token を使わない (持ち主の裁定) CTX2・CTX3
DR2既定と違う席の意志を、 置く／消すだけで戻せる記録で表す — 既定が off の席の on と既定が on の席の off を、 席を休ませるたびの設定の編集なしに (N1・ADR-0070) CTX1・CTX2・CTX4
DR3書き手と決まる順は 1 本 — 明示の記録の書き手は器の口だけで、 実効の値の決まる順は 1 本の関数が持つ (C2・ADR-0070) CTX3・CTX4
DR4値と出所を外から読める — 外の読み手は記録の file でなく口の出力から、 実効の値とどこで決まったかを読む (C10) CTX3・CTX4
03 検討した選択肢 / 3 つの確定方式

それぞれの利点と欠点を並べる

候補を 4 つ並べます。 明示 on と明示 off の 2 つの記録と、 群の表の行の key と、 置き場の種類の既定の順で決める案 (選んだ案)、 今の形のまま park の区画の席に器が停止の記録を書く案、 既定を host 全体の 1 値で持つ案、 明示 on を持たず停止の記録と種類の既定だけにする案です。 選ばなかった 3 案にも利点を並べ、 退けた決め手を各案に書きます。

OPT1明示 on と明示 off の 2 つの記録と default、 決まる順は明示 → 群の表の行の key → 種類の既定採用

口を seat heartbeat on|off|default|status にし、 on は明示 on の記録を、 off は明示 off の記録を席の状態の dir に 1 つ (1 行・時刻) 置いて他方を消し、 default は両方を消す。 heartbeat の実効の値は (1) 明示の記録 (explicit) → (2) 席の置き場が属する群の表の行の任意 key heartbeat (group) → (3) 置き場の種類の既定 (群は on・park の区画は off・群の表のどの行にも属さない席は on・default) の順で決まる。 明示の記録が 2 つとも在る周と在るのに読めない周は off (explicit)。 key の値が on と off の外の host の面は読みで断る。 決まり方を explicit・group・default の閉じた 3 語で出し、 外の読み手は口の出力を読む。 決め手は現物 (持ち主の裁定)。

席ごとの記録を「明示 on」と「明示 off」の 2 つにし、 口を on|off|default|status にする案です。 on と off はそれぞれの記録を 1 つ置いてもう一方を消し、 default は両方を消します。 合図を送るかは、 まず明示の記録、 無ければ席の置き場が属する群の表の行の key、 それも無ければ置き場の種類の既定 (群は送る・park の区画は送らない・どこにも属さない席は送る) の順で決まります。 記録が 2 つとも在る周や読めない周は送りません。 どこで決まったかを 3 語 (explicit・group・default) で出し、 外の読み手は口の出力を読みます。 park の区画の席は何もしなくても合図を受けず、 それでも受けたい席は明示 on で表せます。 代わりに、 記録の file が 2 種になり、 status の項目が増えます。 持ち主の裁定で選びました。

+ 利点

  • park の区画の席は記録も key も無いまま off になり、 何もしなくても合図で token を使わない (DR1)
  • 既定が off の席でも明示 on で合図を受けられ、 既定が on の席でも明示 off で止められる。 どちらも置く／消すだけで戻せる (DR2)
  • 明示の記録の書き手は口 1 本のままで、 群の表の行の key は宣言 1 回で置き場の既定を決める (DR3)
  • 決まり方の語で、 実効の値がどの段で決まったかを外の読み手が口の出力から読める (DR4)

− 欠点

  • 記録の file が 2 種になり、 2 つとも在る周と読めない周の読み (off) を決めて歯で持つ
  • seat tick status の項目が 7 つ・seat heartbeat status の項目が 3 つに増え、 外の読み手の読む key が変わる
  • 決まる順が 3 段になり、 席の値の出所は記録・群の表・置き場の種類の 3 か所に分かれる (口の出力が 1 つにまとめる)
OPT2ADR-0070 の形のまま、 park の区画の席には器が停止の記録を書く不採用

口は off|on|status の 2 値のまま、 席の置き場が park の区画に入る周や席を起動する周に、 器が席の停止の記録を置く。 決め手は分析 (書き手が口の外に増える)。

口は今の 2 値のまま、 席が park の区画に入る周や起動する周に、 器が停止の記録を置く案です。 口の形も記録の種類も status の項目も変わらず、 外の読み手が今までどおり記録の有無を読める点で勝ります。 けれども、 記録の書き手が口の外に増え、 書き手を器の口 1 本にする線が崩れます。 区画から群へ移した席に記録が残って黙って合図を受けなくなり、 park の区画の席で on を撃っても次に器が記録を書く周に戻ってしまいます。 分析で退けました。

+ 利点

  • 口の形と記録の種類 (1 つ) と status の項目が変わらない
  • 外の読み手は今までどおり記録の有無を読める

− 欠点

  • 停止の記録の書き手が口の外 (区画に入れる手・起動の手) に増え、 書き手は器の口 1 本の線が崩れる (DR3)
  • 席を区画から群へ移しても停止の記録が残り、 群の席が黙って合図を受けない (DR1)
  • park の区画の席で on (記録を消す) を撃っても、 次に器が記録を書く周に off へ戻り、 合図を受けたい意志を残せない (DR2)
OPT3既定を host の面に 1 値で持つ (host 全体の on / off)不採用

host の面に heartbeat の既定を 1 値で置き、 停止の記録の無い席はその値に従う。 決め手は分析 (置き場の種類ごとの既定を表せない)。

host 全体の既定を 1 つの値で持ち、 記録の無い席はそれに従う案です。 既定の置き場が 1 つで、 1 行で全席の既定を変えられ、 記録も 1 種のままで済む点で勝ります。 けれども、 群の席は送る・park の区画の席は送らない、 のように置き場の種類ごとに違う既定を表せません。 席ごとに違う値を持たせるには host の設定で席を名指すことになり、 前の決定が退けた「席を休ませるたびに設定を書き換える」形に近づきます。 既定が off の host で合図を受けたい席も表せません。 分析で退けました。

+ 利点

  • 既定の置き場が 1 つで、 宣言 1 行で host の全席の既定を変えられる
  • 停止の記録は 1 種のままで済む

− 欠点

  • 群の席は on・park の区画の席は off のように、 置き場の種類ごとに違う既定を表せない (DR1)
  • 席ごとに既定と違う値を持たせるには host の面で席を名指すことになり、 ADR-0070 が退けた「席を休ませるたびに設定を編集する」形に近づく (DR2)
  • 既定が off の host で合図を受けたい席を表す記録が無い (DR2)
OPT4明示 on を持たず、 停止の記録の有無と置き場の種類の既定だけにする不採用

口は off|on|status のままで、 on は停止の記録を消す。 記録の無い席は置き場の種類の既定 (群は on・park の区画は off・どこにも属さない席は on) に従う。 決め手は分析 (既定が off の席で合図を受けたい席を表せない)。

明示 on の記録を持たず、 停止の記録の有無と置き場の種類の既定だけで決める案です。 記録が 1 種のままで口の操作も増えず、 park の区画の席は何もしなくても送らない点で勝ります。 けれども、 park の区画の席で合図を受けたい席を表せません。 on は記録を消すだけなので、 消した後は種類の既定の「送らない」に戻ります。 on を撃った後の結果が置き場で変わり、 口の操作と結果が食い違います。 分析で退けました。

+ 利点

  • 記録は 1 種のままで、 口の verb も増えない
  • park の区画の席は何もしなくても off になる

− 欠点

  • park の区画の席で合図を受けたい席を表せない。 on は記録を消すだけで、 消した後は種類の既定の off に戻る (DR2)
  • on を撃った後の値が置き場で変わり (群では on・park の区画では off のまま)、 口の操作と結果が食い違う (DR4)
04 採用した判断 / どの方式を選ぶか

選んだ方式と、 それが守る要件 (cross-doc 照会)

選んだ案と、 それが要件書のどの要件を支えるかを示します。 口を seat heartbeat on|off|default|status にし、 合図を送るかを「明示の記録 → 群の表の行の key → 置き場の種類の既定」の順で決め、 どこで決まったかを 3 語で出します。 支えるのは FR78 (heartbeat の決め方と見回りの健全) の根拠と、 FR27 (見回り) と FR95 (park の区画) への主張です。

採用 — OPT1

器 SHALL heartbeat を席ごとに決める口 seat heartbeat on|off|default|status を持ち、 on SHALL 明示 on の記録を、 off SHALL 明示 off の記録を、 それぞれ席の状態の dir に 1 つ (1 行・時刻・一時 file → rename) 置いて他方を消し、 default SHALL 両方を消す (可逆)。 明示 off の記録 SHALL ADR-0070 の停止の記録と同じ置き場と形とし、 既に在る停止の記録をそのまま明示 off と読む。 heartbeat の実効の値 SHALL 次の順で決まる — (1) 明示の記録が 1 つだけ在る周はその値で、 2 つとも在る周と在るのに読めない周は off (決まり方 explicit)、 (2) 明示の記録が無く、 席の置き場が属する群の表の行 (群か park の区画) が任意の key heartbeat (on か off) を持つ周はその値 (group)、 (3) それ以外は置き場の種類の既定で、 群の置き場の席は on・park の区画の置き場の席は off・群の表のどの行にも属さない席は on (default)。 決まる順 SHALL 決まり方の閉じた 3 語 (explicit・group・default) の宣言順として 1 本の関数が持つ。 口の default は明示の記録を消す操作で、 決まり方の default は (3) で決まったことを指す。 群の表の行の key heartbeat が on と off の外の値を持つ host の面 SHALL 読みで断る (fail-closed)。 実効の値が off の席には管理 tick SHALL 合図を送らず (alarm も届かない) 判定行に理由 heartbeat-off を出し、 死んだ席の起こし直し・移動の周の退避・群の移動の判定・park の移り先の判定 SHALL そのまま撃つ。 seat heartbeat status SHALL 実効の値・決まり方・最後の周の打刻の 3 項目を、 seat tick status SHALL 最後の周の時刻・経過・健全・実効の値・決まり方・梯子の段・次の合図の 7 項目を、 doctor の席の行 SHALL 実効の値と健全の 2 項目を出す。 外の読み手 SHALL heartbeat の実効の値を口の出力から読み (記録の file の有無は実効の値でない)、 on・off・default は口を撃つ。 明示の記録の書き手 SHALL 器の口 1 本とし、 管理 tick SHALL NOT 書かない。 最後の周の打刻の形・健全を読み手が判じること・打刻を event log に書かないこと (ADR-0070)・判定の列の順・梯子の列と記録・rules 行 SHALL NOT 変えない。

器は、 合図 (heartbeat) を席ごとに決める口 seat heartbeat on|off|default|status を持ちます。 on は明示 on の記録を、 off は明示 off の記録を席の dir に 1 つ (時刻 1 行) 置いてもう一方を消し、 default は両方を消します (戻せます)。 明示 off の記録は前の決定の停止の記録と同じ置き場と形で、 既に在る停止の記録はそのまま明示 off と読みます。 合図を送るかは次の順で決まります。 (1) 明示の記録が 1 つだけ在ればその値 (2 つとも在る周と読めない周は送らない)、 (2) 無ければ席の置き場が属する群の表の行の key heartbeat の値、 (3) それも無ければ置き場の種類の既定 (群は送る・park の区画は送らない・どこにも属さない席は送る)。 どこで決まったかは explicit・group・default の 3 語で名乗り、 この順は 1 本の関数が持ちます。 key に on と off の外の値を書いた host の面は読みで断ります。 送らない席にも、 落ちた席の起こし直し・移動のための退避・群の移動の判定・park の移り先の判定はそのまま撃ちます。 seat heartbeat status は値・決まり方・最後に周った記録の 3 項目を、 seat tick status は 7 項目を、 doctor の席の行は値と健全の 2 項目を出します。 外の読み手は記録の file でなく口の出力を読み、 on・off・default は口を叩きます。 記録の書き手は器の口 1 本で、 見回りは書きません。 持ち主の裁定は、 park の区画の席には既定で合図を送らないこと (合図で token を使わない) と、 既定が off の席でも合図を受けたい席を表せることでした。 前の決定 (ADR-0070) の口は停止の記録の有無の 2 値で、 記録が無い状態が「送る」に決まっているので、 既定を置き場で変えるには記録が無い状態の意味を種類で変えるしかありません。 そうすると、 既定が off の席で合図を受けたい意志は、 記録を消すだけの on では表せません。 そこで明示 on と明示 off の 2 つの記録を持ち、 どちらも無い席だけが既定に従う形にしました。 器が park の区画の席に停止の記録を書く案を退けたのは、 記録の書き手が口の外に増え、 区画から外した席に記録が残るからです。 host 全体の 1 値を退けたのは、 群は送る・park の区画は送らない、 という種類ごとの既定を表せないからです。 前の決定は、 off を host の設定に持つ案を、 席を休ませるたびに設定の編集と裁定が要るとして退けました。 この記録でも席ごとの休止は口の明示の記録のまま残り、 群の表の行の key は置き場の種類の既定を宣言で 1 回決めるだけなので、 前の決定が避けた費用 (休止のたびの編集) は生じません。 決まる順を 3 語の宣言順として 1 本の関数に持たせるのは、 選定の順を 1 つの列の宣言順だけから取る決まり (C2) に沿うためです。 決まり方を口の出力に添え、 外の読み手に記録の file でなく口の出力を読ませるのは、 既定が置き場で変わると記録の有無と実際に送るかが食い違い、 値がどこから来たかを 1 語で知れる方が読み違えないからです。 2 つとも在る周と読めない周を送らないと読むのは、 合図は確かな証拠があるときだけ送る前の決定の読みを保つためです。 明示 off の記録を前の決定の停止の記録と同じにするのは、 既に止めている席を移し替えなしにそのまま止めておくためです。 status の項目が増え外の読み手の読む key が変わること・記録の file が 2 種になること・key の書き誤りで host の面の読みが止まることは、 代償として引き受けます。
