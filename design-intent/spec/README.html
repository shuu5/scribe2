本 dir (design-intent/spec/) はこの project の design-intent spec (構造・不変条件・WHAT) を集約する cluster です。 spec file は folio framework の rules に従い HTML + JSON-LD で記述します。 共通 stylesheet (common.css) は project root に任意で配置してください。

§1. Purpose

spec/ に置かれた design-intent 文書 (WHAT) の入口です。 scribe2 の折れない線は constitution に、 設計判断の理由は decisions/ に分かれています。

本 README は spec/ cluster の index (entry point) です。 cluster 内の spec を一望し、 reader (人間 / AI agent) のナビゲーションを支えます。 主な人間読者は仕様・要件を参照する導入済みの開発者です — project 全体の俯瞰や他 cluster への入口は design-intent/index.html (landing) が担います。

§2. Contents
