§0. 読み方 — この一覧が何の写しか

このページは scribe2 の要件 doc（repo の外で凍結・v0.1.10）から、 MVP で着手する要件 144 本と、 v2 の開発 session 自身が守る作法 6 本を写したものです。 各行は要件 doc の id をそのまま持ち、 要件定義書（SRS）の各要件がどの行から来たかは、 末尾の §移行表 が示します。 人が読む要旨は章ごとの段落に、 原文の行は各章の折りたたみの中の表にあります。

id 体系 R-<章><番号> は要件 doc のまま （章 = A intake→契約 / B dispatch / C gate / D land / E 席と役割 / F 承認・裁定 / G 口座 / H WM・rebrief / I 台帳 adapter / J 消費 / K 教訓 / P 可観測性・提示面 / Q 移植性・host / R 公開安全 / O 跨版）。 SRS (./srs.html) の各 FR / NFR と本カタログ行の対応は §移行表 が持ち (SRS 側の根拠 field は上位ニーズ N-1〜N-5 を指す)、 各行の id セルは #r-<小文字 id>（例 #r-a1）で deep-link できる。 列の意味: id = 要件 doc の行 id / 要件文 = 原文の要件 1 文（scrub 済み）/ v2 表現 = 原文に ｜v2: field が在る行だけの値（無い行は空）/ 出所 = 原文の ｜出所: field / 裁定 = 原文の ｜裁定: field（user 逐語は落とし、 ts・論点番号・RULING doc 名・承認 relay の scope は残す。 なし = 裁定に紐づかない行、 空 = 原文にこの field が無い行）/ v1 対応物 = 原文の ｜v1: field（- = v1 に対応物なし）/ 備考 = 収録上の注記。 着手 field の意味: 原文末尾の ｜着手: v2 / ｜着手: v3 は要件の効力ではなく着手時期である。 v2 = MVP（縦 1 本を v2 リポ自身で通すのに要る要件）、 v3 = 要件として生きるが着手を次の版へ送る。 本カタログの母集団は 着手: v2 の全 144 行 + 章 H の 6 行 = 150 行で、 それ以外の v3 行は収録せず章ごとの件数だけを見出しに書く。
